🔥 Firebase 설정 (처음 한 번만!)
1
Firebase 프로젝트 만들기
console.firebase.google.com 접속 → 구글 로그인 → 프로젝트 추가
2
Realtime Database 생성
왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 → asia-southeast1 선택 → 테스트 모드
3
웹 앱 추가 후 설정값 복사
프로젝트 설정(⚙️) → 앱 추가 → firebaseConfig 값 복사
💡 설정 완료 후 헤더에 "실시간 동기화 중" 초록불이 켜지면 성공!
🚀 사용 방법
1
비밀번호 설정
앱 첫 실행 시 4자리 PIN 설정. 팀원 모두 같은 번호 사용.
2
이달 총원 입력
매달 1일, 화면 하단 이달 인원 변동 등록에서 기준 총원 입력.
3
매일 업무일지 작성 후 저장
부별 출석 입력 → 결석 자동계산. 저장하기 누르면 팀원들에게 알림 자동 전송!
💡 저장 시 팀원들 폰에 자동 알림이 전송됩니다!
📱 홈 화면에 앱처럼 추가
A
아이폰 (Safari)
링크 접속 → 하단 공유(□↑) → 홈 화면에 추가
B
안드로이드 (Chrome)
링크 접속 → 우측 상단 ⋮ → 홈 화면에 추가
✅ 홈 화면 추가 시 앱 아이콘으로 바로 실행!
